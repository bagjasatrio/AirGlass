# QA audit, 26 Oct 2026

Scope: the receiver at `C:\project\airglass` (build `Release`, v0.2.0 line) and the
landing page at https://airglass.vercel.app. Evidence is local runs plus HTTP
checks against the deployed site. No external scanner was used.

## Findings and status

| # | Finding | Severity | Evidence | Status |
| --- | --- | --- | --- | --- |
| A1 | Preset contract leaked: `Mirror resolution`, `Frame rate cap` and the GPU toggle wrote `live_settings` at any time, including mid-session, so a running session could be renegotiated behind the user | High | `video_renderer.cpp` write sites at 2463/2501/2522/2652 | Fixed: controls are disabled while a device is connected and the section states why |
| A2 | UI offered 1440p, 4K and 2868-square canvases while the docs claim a 1080p short-side ceiling | High | preset table in the resolution section | Fixed: only `1920x1080` and `1920x1920` remain, custom range clamped to 1920 |
| A3 | Invalid command line was invisible: `--preset nonsense`, `--mirror-res abc`, unknown flags printed nothing and started the receiver with defaults | Medium | `airglass.exe --bogus-flag` ran until killed, exit 124 | Fixed: message on stderr, dialog only when stderr is unattached, exit code 2 |
| A4 | `--mirror-res` without an `x` separator fell through silently | Medium | `--mirror-res abc` timeout instead of error | Fixed with an explicit else branch |
| A5 | No automated coverage for the command line | Medium | only `tests/smoke/test_probe.py` existed | Fixed: `tests/cli/test_cli.py`, 11 cases, all passing |
| A6 | No CSP, framing or permissions policy on the site | Medium | `curl -I` showed only HSTS, nosniff, referrer policy | Fixed: CSP, `frame-ancestors 'none'`, `X-Frame-Options`, `Permissions-Policy`, COOP |
| A7 | `/api/download` answered `302` to `POST`, so any crawler or bot could spend the GitHub API quota | Low | `curl -X POST` returned 302 | Fixed: `405` with `Allow: GET, HEAD` |
| A8 | Unknown paths returned the raw Vercel 404 | Low | `/nope` | Fixed: branded `404.html` |
| A9 | Footer links were 15 px tall, under the 24 px WCAG 2.2 target size | Low | computed heights on the live page | Fixed: 6 px block padding |
| A10 | The page fired a `fetch('/api/download')` probe on every load, which showed up as a failed request and spent a GitHub API call | Low | resource timing showed a 0-byte `download` entry | Fixed: probe removed, releases page linked in the download note instead |
| A11 | Social metadata was incomplete: no `og:url`, no `og:site_name`, no Twitter title/description, relative `og:image` | Low | HTML head | Fixed |
| A12 | `frame-ancestors` missing meant the page could be framed by anyone | Low | headers | Fixed (same change as A6) |
