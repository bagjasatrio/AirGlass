# Glasscast v0.1 — QA Audit

**Tanggal:** 2026-10-22
**Cakupan:** repo `glasscast` (engine fork + 5 modul Glasscast), build Release x64 di mesin ini
**Metode:** build bersih, smoke test otomatis, soak test, uji CLI nyata, inspeksi UI lewat screenshot, pembacaan kode per kategori
**Status:** semua angka di bawah berasal dari eksekusi nyata di mesin ini. Yang tidak bisa diuji ditandai eksplisit, bukan diasumsikan lulus.

## 6. Temuan

### F1 — Panel OPTIONS upstream masih bisa mengubah resolusi saat sesi (TINGGI)
Kontrak "preset dikunci selama sesi" dilanggar oleh kombo `mirror_res` di panel OPTIONS warisan upstream. Perbaikan v0.1.1: sembunyikan kombo itu, atau labeli "berlaku pada koneksi berikutnya" + catat di log saat diubah.

### F2 — CPU idle masih 25%+ satu core (SEDANG)
Setelah throttle 33 ms/frame: 25,6% tipikal, spike hingga 99% saat interaksi UI. Di mesin 16 core dampaknya kecil; di laptop 2C/4T ini berarti ~25% CPU hanya untuk layar idle. Perbaikan: idle 10 fps + hentikan redraw penuh saat window tidak fokus.

### F3 — Klik baris preset belum terverifikasi otomatis (SEDANG)
`Selectable` + `SpanAllColumns` lolos code review dan modal tampil benar, tapi harness klik sintetis tidak menembus window SDL. Butuh satu uji manual manusia: klik baris → modal hilang → log `Pre-flight preset chosen`.

### F4 — Audio belum diuji dengan iPhone (TINGGI)
Alasan utama proyek ini (audio tidak hilang/telat) belum punya bukti runtime. Yang ada: WASAPI event-driven + `IMMNotificationClient` + `swresample` terkompilasi dan ter-link; jalur SDL lama sudah dilepas dari build.

### F5 — `libplist` sempat ter-link dari `debug/lib` (SEDANG, diperbaiki)
Konfigurasi awal memilih `installed/x64-windows/debug/lib/plist-2.0.lib` untuk build Release. Sekarang dipin ke `lib/plist-2.0.lib`; build bersih ulang mengonfirmasi `lib=.../x64-windows/lib/plist-2.0.lib`.

### F6 — Teks log preset ganda (RENDAH, diperbaiki)
`(effective 1080p60, 1080p60)` → sekarang `auto (effective 1080p30) canvas=1080p30`.

### F7 — `vcpkg.json` upstream dinonaktifkan (INFORMASI)
Manifest mode gagal karena baseline commit tidak ada di clone `--depth 1`, dan akan mengompilasi FFmpeg dari source (20–45 menit). Diganti `vcpkg.json.upstream`; dependensi dideklarasikan di README + CI.

## 7. Kesimpulan

**Terbukti jalan di mesin ini:** build bersih dari nol, probe kapabilitas dengan verdict masuk akal, empat preset (tiga tetap + auto), persistensi preferensi, penerapan preset ke kanvas/fps/hwaccel, mDNS native tanpa Bonjour, diagnosis profil jaringan Public, RSS 62 MB, modal pre-flight bersih secara visual.

**Belum terbukti:** semua yang butuh iPhone — mirror 1080p, audio tidak telat, audio selamat dari ganti device, DRM tetap hitam sesuai janji, latency dan A/V skew. Sampai diuji, klaim utama proyek masih klaim desain, bukan hasil ukur.

**Risiko terbesar sebelum dipakai harian:** F4 (audio belum terbukti) dan F1 (kunci preset bocor lewat panel OPTIONS).
